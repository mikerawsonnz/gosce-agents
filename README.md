# GOSCE Agents

A portfolio of production **remote MCP + A2A agents** running on [getvda.ai](https://getvda.ai/agents), discovered + quality-assured by the **[GOSCE Portfolio Router](https://router.getvda.ai)**. Each agent is capability-scoped, speaks open A2A + MCP, and is metered with Nevermined x402 micropayments (discovery is free).

Generated by **GOSCE** (GitHub Open-Source Combination Engine) — an automated pipeline that mines the OSS dependency graph for monetizable package combinations and deploys each as a verified agent.
